# Prior art: what has been done, and what has not

**If you are reviewing this project and think it has been done before: much of it has. Read this page first, then decide what has not been done.** Other PayPal AI Hackathon 2026 entries test PayPal checkouts too, some of them on real open-source shops. Each row below says what the other work does, as its own public README describes it on the date given, and where the difference can be checked in this repository.

## What is new, written so it can be refuted

What we have not found elsewhere is all of it in one loop for a PayPal checkout: an AI that invents robberies against the checkout itself, from what any visitor sees and with no person describing them, judged only by reconciling the shop's books with PayPal's records; ten scripted robberies, each proven on every push to catch its own mistake; a coding agent that adds or fixes the integration from PayPal's own answers; and a pull-request gate, offline or in the sandbox. That combination is the claim, as of 2026-11-08. If you know work that does all of it, open an issue with a link and we will add it here.
