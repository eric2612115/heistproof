# Claims ledger

Every claim this project makes in its README, its submission text or its video, with what produces it and where to check it. A claim is **VERIFIED** when the named test passes in CI (`npm test`, `npm run test:attacks`) or the named recording in `runs/` shows it; a claim without that is **UNVERIFIED** and is not made anywhere public. Recorded runs carry the commit and the source fingerprint they were made with, and `test/evidence.test.ts` fails if any recording does not match the code in this repository, or if the README's evidence table was edited by hand.
