# Claims ledger

Every claim this project makes in its README, its submission text or its video, with what produces it and where to check it. A claim is **VERIFIED** when the named test passes in CI (`npm test`, `npm run test:attacks`) or the named recording in `runs/` shows it; a claim without that is **UNVERIFIED** and is not made anywhere public. Recorded runs in `runs/` record the commit and source fingerprint they were made with, written by Heistproof into each run's own files, and `test/evidence.test.ts` fails if the README's evidence table was edited by hand instead of being generated from those runs. Runs in `runs/archive/` were made with earlier code (the 2026-11-07 one before fingerprints existed) and are kept as evidence of what happened then.
